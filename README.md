# 2048 (Unity) — Логика инициализации

## 📋 Описание

Это простая заготовка игры **2048**, сделанная в Unity.  
В этой версии реализована **логика инициализации игрового поля** — то есть создание клеток с числами в случайных позициях при запуске игры.

---

## 🔄 Как работает инициализация

### 1. У нас есть 16 пустых ячеек

На сцене заранее расставлены 16 UI-элементов — это просто фоновые ячейки.  
У каждой из них есть компонент `CellPosition`, который хранит её координаты в сетке (`x` и `y`) и информацию, занята она или нет.

### 2. Есть отдельный контейнер для игровых клеток

Когда появляется новая клетка (например, число 2 или 4), она создаётся **поверх фона** в другом контейнере `activeCellsContainer`.  
Её позиция берётся из соответствующей пустой ячейки.

### 3. При запуске создаются 2 клетки

Когда запускается сцена:
- Скрипт `GameField` ищет все свободные ячейки
- Выбирает 2 случайные
- В каждую создаётся `CellView` — это визуальная клетка с числом
- Число выбирается случайно:
  - 90% — это 2 (в степени: `value = 1`)
  - 10% — это 4 (`value = 2`)
- Клетка появляется в том месте, где находится выбранная пустая ячейка
- Размер и позиция задаются точно по макету

---

## 💡 Как работает позиционирование

- Позиция берётся в **мировых координатах** у пустой ячейки
- Клетка создаётся и получает **эту же мировую позицию**
- Таким образом, она появляется **точно на месте** выбранной фона
